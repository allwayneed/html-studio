# HTML Studio

ブラウザだけでHTMLサイトを組める、GUI編集つきビルダー。

## 機能
- **HTML / CSS / JS の3タブエディタ**（保存で自動プレビュー、内容は自動保存）
- **GUI編集モード**: プレビュー内の要素をクリックするだけで、色・サイズ・余白・flex/grid設定をパネルから編集 → ボタンひとつでHTMLソースに書き戻し
- **スクリプト注入**: JSタブに書いたコードはプレビューで実際に動く（サンドボックス付き）
- **XSS自動検査**: ボタンひとつで、innerHTML / eval / document.write / javascript: URL などの危険パターンを危険度つきでレポート（行番号・修正案つき）
- **単一HTMLエクスポート**: HTML+CSS+JSを1ファイルに結合してダウンロード

## 使い方
GitHub Pages で公開中: https://allwayneed.github.io/html-studio/

1. 開いたら左でコードを書く、右でプレビュー
2. 見た目を変えたくなったら「GUI編集」→ 要素をクリック → 右パネルで調整 →「ソースへ反映」
3. 書き終えたら「XSS検査」→ 「単一HTMLで保存」

ローカルでも `index.html` を開くだけで動く。サーバー不要。
